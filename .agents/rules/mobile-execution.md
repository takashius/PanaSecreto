# Mobile Execution & Build Rules

- **Expo Go Only**: Toda ejecución y prueba de la aplicación móvil (`apps/mobile`) debe ser únicamente mediante Expo Go (`expo start`).
- **PROHIBIDO `expo export`**: Queda estrictamente prohibido ejecutar `expo export` o cualquier variante de empaquetado/exportación estática. No ejecutarlo bajo ningún concepto ni preguntar/sugerir hacerlo.
